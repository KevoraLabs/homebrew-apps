Quick Start

快速安装与更新

你可以直接通过完整的 Cask 名称一步安装，或者先添加 KevoraLabs Tap 再进行管理。

方法一：直接单行命令安装（推荐）

无需手动添加 Tap，Homebrew 会自动抓取并安装对应的软件：

brew install --cask KevoraLabs/tap/key-launch brew install --cask KevoraLabs/tap/pause-loop

方法二：先添加 Tap 仓库

添加后可以随时搜索和安装 KevoraLabs 的所有 Cask：

brew tap KevoraLabs/tap brew install --cask key-launch

后续如何保持更新？

新版本发布后，在终端运行相应的 upgrade 命令即可升至最新版：

brew upgrade --cask key-launch brew upgrade --cask pause-loop
FAQ & Quarantine

首次启动“无法打开”解决办法

若由于 macOS 隔离机制（Quarantine）导致首次打开弹出安全提示，只需在终端运行以下命令清除隔离标记即可：

xattr -dr com.apple.quarantine /Applications/KeyLaunch.app
xattr -dr com.apple.quarantine /Applications/PauseLoop.app
xattr -dr com.apple.quarantine /Applications/WeChatMulti.app
